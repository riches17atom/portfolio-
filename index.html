# AWS Provider Configuration
terraform {
  required_version = ">= 1.5.0"
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}

provider "aws" {
  region = "ap-south-1"
}

# Virtual Private Cloud
resource "aws_vpc" "main" {
  cidr_block           = "10.0.0.0/16"
  enable_dns_hostnames = true
  enable_dns_support   = true

  tags = {
    Name        = "production-vpc"
    Environment = "production"
    ManagedBy   = "Terraform"
  }
}

# Public Subnet
resource "aws_subnet" "public" {
  vpc_id            = aws_vpc.main.id
  cidr_block        = "10.0.1.0/24"
  availability_zone = "ap-south-1a"
}

Kubernetes Architecture & Lifecycle Explained

Container orchestration principles implemented by Riches Thapa

In containerized production environments, Kubernetes coordinates the state of workloads through declarative manifest definitions:

  • Control Plane: Constantly monitors cluster state via etcd and schedules pod placement with kube-scheduler.
  • Worker Nodes: Run container engines via containerd and coordinate network routing via kube-proxy.
  • Deployments & Pods: Manage rolling updates with zero downtime, auto-healing terminated containers instantly.
  • Services & Ingress: Provide deterministic internal DNS routing and external HTTPS entrypoints.
