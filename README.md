## 🌐 How to Deploy to `richeshthapa.com.np`

### With GitHub Pages:
1. Push this folder to your GitHub repo (e.g. `https://github.com/riches17atom/portfolio`).
2. Go to repository **Settings** &rarr; **Pages** &rarr; Select `main` branch root.
3. In **Custom domain**, enter `richeshthapa.com.np`.
4. Update your DNS CNAME/A records at Register.com.np.

### With Vercel / Netlify / Cloudflare Pages:
1. Drag and drop or link your GitHub repo.
2. Zero build command needed (Static HTML).
3. Assign custom domain `richeshthapa.com.np`.
